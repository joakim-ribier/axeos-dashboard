{%- comment -%} Renders one top-level nav
  • (with its optional anchor subnav) for a single page. Factored out of site_nav.html so it can be called both for ungrouped pages and for pages nested inside a "group" wrapper. Usage: {% include components/nav_item.html node=some_page %} Every page's own subnav starts collapsed by default -- toggled by hand, via the arrow or the label click handled in head_custom.html. The theme's own built-in behaviour still force-expands whichever item's subnav contains the current page on load. Every link also carries a data-nav-key equal to its own href, for head_custom.html's collapse-state persistence to key off instead of the live href attribute -- the theme's own scrollNav() (just-the-docs.js) strips href from whichever link matches the current page, so reading getAttribute("href") there returns null and would silently corrupt that item's stored state (and, since every stripped link reads back the same null, merge it with any other currently-on-that-page item's state too). {%- endcomment -%}
