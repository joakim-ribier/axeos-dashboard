# v0.1.0

Première version taguée de axeos-dashboard — un point de repère stable,
distinct du build `latest` qui suit chaque push sur `main`.

## Images Docker

- `ghcr.io/joakim-ribier/axeos-dashboard/axeos-services:0.1.0`
- `ghcr.io/joakim-ribier/axeos-dashboard/axeos-dashboard:0.1.0`

```bash
curl -fsSL https://raw.githubusercontent.com/joakim-ribier/axeos-dashboard/main/docker-install.sh | IMAGE_TAG=0.1.0 bash
```

Voir [Installation](installation.html#docker-installation) pour le détail
de `IMAGE_TAG`.
